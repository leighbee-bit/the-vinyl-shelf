    How to connect Last.fm
    1. If you haven’t already, link Spotify to Last.fm (Last.fm → Settings → Applications → Spotify Scrobbling) so it records what you play.
    2. Create a free API key at last.fm/api/account/create. Any app name works; leave the callback URL blank.
    3. Paste your username and the API key (not the shared secret) below.
